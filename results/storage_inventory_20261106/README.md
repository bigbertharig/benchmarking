# Model store reconciliation — 2026-11-06

The canonical model store is the 4 TB share at `/mnt/shared/models/<model_id>/` on the rig (`/media/bryan/shared/models/<model_id>/` on the Pi). The NVMe `/data/model-hotset/<model_id>/` is a runnable cache. Model identifiers and published paths come from the benchmarking library; orchestration resolves a loaded model against the NVMe cache and canonical archive. The gateway routes requests and does not own a second list of weight paths. All 299 blocks in the tracked campaign manifests now name model IDs without a GGUF path; each resolved through the model registry in the 2026-11-06 check.

A complete bundle includes GGUF weights **and** any required runtime artifacts. Strata's Qwen3.8 Q2 bundle has 66,423,878,624 bytes of GGUF weights and 35,469,412,079 bytes of pack files (101,893,290,703 bytes total). Its pack contains expert and dense data, metadata, and tokenizer files; the 35.5 GB is required for the tested Strata runtime. It was originally downloaded and prepared on NVMe, so the 4 TB copy was missing. `scripts/analysis/sync_model_bundle.py` mirrored the exact files into the matching archive folder, verified SHA-256 per file, and wrote `bundle_manifest.json` with each role and the total. The completed receipt is `q2_bundle_sync.json`.

The existing Qwen3.6 35B Strata pack consists of 9,843,821 bytes of tokenizer artifacts. Its complete, hash-verified bundle totals 22,863,506,829 bytes across six files. The registry stores `prepared_pack_size_bytes` and `bundle_size_bytes` inside each Strata profile; these are disk accounting fields. The existing `model_size_bytes` and `ngram_size_bytes` remain model-placement fields. Future Strata packs should live under `<model_id>/runtime/<pack_name>/` in the archive and be staged into the runtime cache from there. The runtime's current staging paths are still in use; this inventory does not change a live model load. An NVMe inventory must count the Q2 hotset GGUFs (61.86 GiB) and its prepared pack (33.03 GiB) as one 94.9 GiB model bundle. Of the 38.7 GiB under `/data/bench-staging`, 33.03 GiB is that pack. The remaining ~5.7 GiB is Strata software, download archives and small probes.
