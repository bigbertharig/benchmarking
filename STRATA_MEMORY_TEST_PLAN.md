## Question and primary endpoint

First, how does the existing Nemotron GGUF perform with one 3090 Ti, host RAM and NVMe backing, compared with its existing six-card placement? Second, can Strata run the supported Qwen3.6 UD-Q4_K_XL GGUF? If so, for the same file, card, context, prompt, output cap and one concurrent request, does it improve latency or throughput per unit of combined VRAM, host RAM and SSD activity? Report a Pareto comparison, not a single score. A RAM saving that substantially increases SSD faults or lowers decode rate is a tradeoff, not an unconditional win.
